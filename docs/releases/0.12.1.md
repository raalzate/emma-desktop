## EMMA 0.12.1 · beta

EMMA 0.12.1 corrige un error de «Teach me»: la tarjeta de gramática podía nombrar
mal el tiempo verbal (por ejemplo, llamar «presente simple» a una frase en presente
continuo como «You are connecting…»).

### Cambios

- **El tiempo verbal ahora se verifica.** Cuando la forma del verbo no deja dudas
  (be + -ing, have + participio, will, did…), EMMA comprueba el tiempo que propone
  la IA y lo corrige si no coincide. También marca bien los dos verbos de los
  tiempos continuos («are» + «connecting»).

### Descargas

| SO | Archivo | Cómo abrir la primera vez |
|---|---|---|
| macOS (Apple Silicon) | `EMMA-0.12.1-arm64.dmg` | clic derecho → Abrir (la firma es ad-hoc: doble clic muestra «no se puede verificar») |
| Windows | `EMMA.Setup.0.12.1.exe` | SmartScreen: «Más información» → «Ejecutar de todas formas» |
| Linux | `EMMA-0.12.1.AppImage` | `chmod +x` al archivo y ejecutarlo |

### Requisitos

- Para la IA local: GPU con **WebGPU**. Sin WebGPU, podés usar la nube con una
  llave propia de Google Gemini.
- Sin cambios de datos respecto de la 0.12.0.
