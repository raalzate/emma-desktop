## EMMA 0.13.3 · beta

EMMA 0.13.3 hace que las actualizaciones se vean y funcionen: la app te avisa
cuando hay una versión nueva y los botones de Ajustes → Updates responden.

### Cambios

- **Aviso de versión nueva en toda la app.** Cuando sale una versión, aparece
  «EMMA X is available» en la barra lateral y te lleva a Ajustes. Antes el aviso
  sólo llegaba si Ajustes estaba abierto justo al arrancar.
- **Los botones de Updates funcionan.** «Check for updates», descargar e instalar
  no hacían nada: sus canales nunca se habían conectado. En Windows y Linux la
  versión nueva se descarga e instala al aceptar; en macOS se abre la descarga.
- **Instalador de Windows con nombre sin espacios** (`EMMA-Setup-0.13.3.exe`), el
  mismo que anuncia el archivo de actualizaciones.

**Si tenés la 0.13.2 o una anterior, descargá esta versión desde esta página:** esas
versiones no tienen los botones conectados ni el aviso. Desde la 0.13.3, las
siguientes te van a aparecer solas.

### Descargas

| SO | Archivo | Cómo abrir la primera vez |
|---|---|---|
| macOS (Apple Silicon) | `EMMA-0.13.3-arm64.dmg` | clic derecho → Abrir (la firma es ad-hoc: doble clic muestra «no se puede verificar») |
| Windows | `EMMA-Setup-0.13.3.exe` | SmartScreen: «Más información» → «Ejecutar de todas formas» |
| Linux | `EMMA-0.13.3.AppImage` | `chmod +x` al archivo y ejecutarlo |

### Requisitos

- Sin cambios respecto de la 0.13.2.
